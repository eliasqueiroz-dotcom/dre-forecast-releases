# DRE Forecast Automatizado — Downloads

Página oficial de **downloads e atualizações** do DRE Forecast
Automatizado (o código-fonte é privado; este repositório distribui
apenas os instaladores).

## Como instalar

1. Baixe o `DRE_Forecast_Setup_<versão>.exe` mais recente em
   **[Releases](../../releases/latest)**.
2. Execute o instalador e siga o assistente (não pede administrador).
   O SmartScreen pode avisar na primeira execução — clique em
   "Mais informações" → "Executar assim mesmo".

## Atualizações

O programa pode verificar automaticamente (se você permitir) ou pelo
botão **"Verificar atualização"** — a consulta lê apenas o arquivo
`versao.json` deste repositório; nenhum dado seu é enviado.
